# Python OOP Advanced

A collection of advanced Python concepts demonstrated with working code.

## Topics Covered

| File | Concept |
|------|---------|
| `inheritance.py` | Class inheritance, super(), polymorphism |
| `generators.py` | Generators, yield, generator expressions, Fibonacci |
| `decorators.py` | Function decorators, decorator factories, @syntax |
| `concurrency.py` | Multi-threading, thread lifecycle, daemon threads |

## Running the Examples

Each file can be run standalone:

```bash
python inheritance.py
python generators.py
python decorators.py
python threading.py
```
